# Планировщик задач

Учебный проект на Vue 3 — одностраничное приложение для управления задачами.

## Технологии

- Vue 3 (Options API)
- Vite
- Bootstrap 5.3

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173).

## Функциональность

- Добавление задачи с названием, описанием, приоритетом и категорией
- Отметка задачи как выполненной
- Удаление задачи
- Фильтрация по категории и статусу
- Счётчики задач (всего / выполнено / в работе)
- Адаптивная вёрстка (мобильный, планшет, десктоп)
